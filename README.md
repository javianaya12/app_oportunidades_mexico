# App Oportunidades México

MVP en Streamlit para identificar oportunidades de negocio en un mapa de México usando datos de negocios, población y scoring de zonas.

## Contenido

Este repositorio contiene el proyecto comprimido:

- `mvp_oportunidades_mexico.zip`

## Funciones principales

- Mapa interactivo con OpenStreetMap.
- Filtros por ciudad y tipo de negocio.
- Scoring de oportunidades.
- Ranking de zonas.
- Exportación a Excel y PDF.
- Datasets simulados para pruebas.

## Cómo correr la app

1. Descargar el archivo `mvp_oportunidades_mexico.zip`.
2. Descomprimirlo.
3. Abrir la carpeta del proyecto.
4. Instalar dependencias:

pip install -r requirements.txt
